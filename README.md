One complete story in exactly six words:

> "She said yes. He said nothing."

A proposal answered, a silence that says everything the answer didn't — the whole wedding, the whole marriage, and the whole undoing, in six words.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the six-word story to `out/entry.txt` (30 characters, 6 words).
